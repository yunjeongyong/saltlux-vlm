### 3-3. 합성 데이터 품질 사고와 대응

폰트 하나(`DejaVuSansDisplay.ttf`)가 글리프가 없어 **아무것도 렌더링하지 않았습니다.**
라벨은 Bold 폰트라 정상 출력되고 값만 비어, **이미지에 없는 내용을 정답으로 주는**
데이터가 각 600여 건 생성됐습니다. bbox 시각화 과정에서 발견해 전량 폐기·재생성했습니다.

재발 방지로 생성기 기동 시 폰트를 자동 검증합니다.

```python
def _usable(path):
    """글리프가 없어 아무것도 안 그리는 폰트를 걸러낸다."""
    return 렌더_어두운픽셀("ABC abc 123 CO., LTD.") > 100
FONT_SETS = [fs for fs in FONT_SETS if all(_usable(p) for p in fs)]
```

생성 후 잉크 밀도 검사도 추가했습니다.
