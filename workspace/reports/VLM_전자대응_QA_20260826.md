# Document Studio 문서파싱 — 전자 대응 Q&A

2026-08-26 · 용윤정 · 초안

전자 측 의견 *"ChatGPT로는 되는데 Document Studio로는 안 된다"* 에 대한 대응 자료입니다.
**학습 전/후 개선폭이 아니라, 현재 모델을 동급 오픈 모델·글로벌 서비스와 비교하는 구성**입니다.

---

## 비교 3축

| 축 | 대상 | 의미 |
|---|---|---|
| ① | **Qwen3.6-35B-A3B** (학습 전 원본) | 동급 사이즈 오픈 모델 |
| ② | **Document Studio** | 전처리 + VLM 제품 단위 |
| ③ | **ChatGPT (GPT5.5)** | 글로벌 서비스 수준 |

**메시지** — 동급 오픈 모델보다 우위이며, 글로벌 서비스와 견줄 수준.

---

## Q1. ChatGPT 대비 성능은 어떻습니까?

**현재 답변 불가 — 측정이 필요합니다.**

GPT API 연동·키가 확보되지 않아 동일 평가셋(SS 400건) 측정을 못 했습니다.
**3축 중 가장 중요한 축이 비어 있어, 대응 전 반드시 확보해야 합니다.**

> 참고: 강한빛 선임님이 정답 생성에 GPT-5.6 을 쓰셨고 400건에 약 $4.6 소요.
> 파싱 비교도 유사 규모로 예상됩니다.

**→ 액션: API 키·예산·담당 확정 (최우선)**

---

## Q2. 동급 오픈 모델보다 나은 근거가 있습니까?

**있습니다.** 같은 평가셋에서 학습 전 원본 모델 대비 전 지표가 개선됐습니다.

영수증 크롭 1,019건 기준:

| 지표 | Qwen3.6 원본 | 학습 모델 (exp_009) | |
|---|---|---|---|
| 표 구조 정확도 (TEDS) | 0.6647 | **0.7476** | **+12.5%** |
| 글자 오류율 (CER) | 0.1378 | **0.1155** | **−16.2%** |
| 완전일치율 | 57.9% | **63.5%** | **+5.6%p** |
| 표 파싱 실패 | 13건 | **3건** | **−77%** |

SS 도메인 400건 기준 측정도 진행 중입니다(receipt 완료, 나머지 내일 오전).

---

## Q3. 정확도가 90%도 안 되는데 쓸 수 있습니까?

**파싱 정확도와 실사용 만족도는 다릅니다.**

영수증 텍스트 921건을 오류 성격별로 분해했습니다.

| 구분 | 건수 | 비율 |
|---|---|---|
| 완전일치 | 591 | 64.2% |
| **틀렸으나 숫자는 전부 정확** | **232** | **25.2%** |
| 숫자가 틀림 (크리티컬) | 98 | 10.6% |

**틀린 330건 중 232건(70.3%)은 숫자가 정확하고 글자만 다릅니다.**
파싱 결과를 RAG 형태로 LLM에 입력하면 보정되는 유형입니다.

> **파싱 정확도 64.2% → 실효 사용성 89.4%**

금액이 틀리는 크리티컬 오류는 **10.6%** 이며, 그중 대부분이 일반 텍스트 라벨입니다.

## Q4. 지적하신 케이스(둥근 폰트·구겨진 영수증)는 개선됐습니까?

**개선 사례가 확인됩니다.** SS 평가셋 receipt 100건 기준, 표 정확도에서 크게 앞선 사례:

| 문서 | Document Studio | 학습 모델 (exp_009) |
|---|---|---|
| receipt03 | 0.333 | **1.000** |
| receipt20 | 0.416 | **0.955** |
| receipt02 | 0.667 | **1.000** |
| receipt53 | 0.831 | **1.000** |

응답이 끝나지 않고 생성 상한까지 가던 **반복 출력 오류도 7건 → 0건**으로 해소됐습니다.
실서비스에서 139초 지연을 유발하던 유형입니다.

**→ 액션: 원본 이미지 + 파싱 결과 비교 화면 제작 (발표 자료용)**

---

## Q5. Document Studio 가 못하는 케이스도 있습니까?

**있습니다. 숨기지 않고 함께 제시하는 것이 맞습니다.**

receipt 100건 중 학습 모델이 뒤진 사례:

| 문서 | Document Studio | 학습 모델 |
|---|---|---|
| receipt87 | 0.875 | **0.014** |
| receipt05 | 1.000 | 0.333 |
| receipt25 | 1.000 | 0.667 |

`receipt87` 은 반복 생성으로 처리에 8분이 걸린 케이스입니다.
**디코딩 설정(`no_repeat_ngram_size=8`)으로 개선 가능한 것을 이미 확인**했으며, 적용 후 재측정 예정입니다.

## Q6. 계속 좋아지고 있습니까?

**예. 실험별로 추적하고 있습니다.**

| 실험 | 표 구조 (TEDS) | 비고 |
|---|---|---|
| 학습 전 원본 | 0.6647 | |
| exp_004 (현 배포) | 0.7079 | |
| **exp_009 (신규)** | **0.7476** | 내부 목표 0.739 첫 달성 |

SS 평가셋 KIE 정확도에서도 exp_009 가 exp_004 를 상회합니다(0.8981 vs 0.8956).
