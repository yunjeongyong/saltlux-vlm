## 2. 모델 구성

**베이스 (공통)** — `/data/workspace/yyj/data/vlm_exp34/ml/models/Qwen3.6-35B-A3B` (67GB)
`Qwen3_5MoeForConditionalGeneration` / vocab 248,320 / hidden 2,048 / 40층 / 전문가 256개(토큰당 8개 활성)

| | exp_004 | exp_009 |
|---|---|---|
| 어댑터 경로 | `.../vlm_exp34/ml/runs/exp004-260813` | `.../vlm_exp34/ml/runs/exp009-final24646` |
| md5 | `b22b5ca08e787cd728497fb517c437ef` | `d23a98b03d0643d74a3ba4c347d45815` |
| 크기 | 132MB | 205MB |
| LoRA r / alpha / dropout | **16 / 32** / 0.05 | **64 / 128** / 0.05 |
| 학습 step | 2,794 | 24,646 |
| 학습셋 | 11,173행 | 86,256행 |

**LoRA 대상 10종 (공통)**
`q_proj` `k_proj` `v_proj` `o_proj` `in_proj_qkv` `in_proj_z` `out_proj` `gate_proj` `up_proj` `down_proj`
**추가 학습** `modules_to_save = ["model.visual.merger"]` (aligner) / **ViT 동결**

**병합하지 않았습니다.** 베이스를 로드한 뒤 PEFT 로 어댑터를 얹는 방식입니다.

```python
model = AutoModelForImageTextToText.from_pretrained(
    "/data/workspace/yyj/data/vlm_exp34/ml/models/Qwen3.6-35B-A3B",
    dtype=torch.bfloat16, device_map="auto")
model = PeftModel.from_pretrained(model, "<어댑터 경로>")
```

## 4-1. 재현 명령 (그대로 복사해서 실행)

모든 경로는 절대경로입니다. 세 단계를 순서대로 실행하면 동일한 수치가 나옵니다.

### 입력 데이터

| | 경로 |
|---|---|
| 평가 이미지 400장 | `/data/workspace/yyj/data/ss_eval/data/<도메인>/images/` |
| KIE 정답 400건 | `/data/workspace/yyj/data/ss_eval/kie_dataset/<도메인>/` |
| DocStudio 기준선 | `/data/workspace/yyj/data/ss_eval/test_output.json` (base)<br>`/data/workspace/yyj/data/ss_eval/test_output_alt.json` (high) |

도메인은 `receipt` `quotation` `invoice` `bill` 네 가지입니다.

### ① 파싱 — 이미지 → 마크다운

```bash
cd /data/workspace/yyj/data/vlm_exp34

# exp_004
CUDA_VISIBLE_DEVICES=4,5,6 PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
python3 scripts/parse_ss_docs.py \
  --model   ml/models/Qwen3.6-35B-A3B \
  --adapter ml/runs/exp004-260813 \
  --types   receipt \
  --out     /data/workspace/yyj/data/ss_eval/vlm_output/exp004 \
  --max-new 3072 --max-px 4000000

# exp_009 — 어댑터만 교체
#   --adapter ml/runs/exp009-final24646
#   --out     /data/workspace/yyj/data/ss_eval/vlm_output/exp009

# 학습 전 원본 — 어댑터 없이
#   --adapter NONE
#   --out     /data/workspace/yyj/data/ss_eval/vlm_output/base
```

이미 만들어진 `.md` 는 건너뛰므로 중단 후 재실행해도 이어집니다.
소요는 도메인별로 다릅니다 — receipt 약 100분, quotation 약 6시간(GPU 3장 기준).

### ② KIE 추출 — 마크다운 → 필드 JSON

```bash
cd /data/workspace/yyj/data/ss_eval

python3 scripts/kie_from_parsing_vlm.py \
  --parsing-dir vlm_output/exp004 \
  --kie-dir     vlm_output/exp004_kie \
  --types       receipt \
  --api-url     http://124.198.30.179:15006/v1 \
  --api-model   public/gemma-4-31B-it \
  --api-key     ""
```

GPU 를 쓰지 않습니다(외부 API 호출). 100건에 약 12분.
`--api-key ""` 로 빈 문자열을 넘겨야 합니다 — 셸에서 따옴표가 사라지면 인자 오류가 납니다.

### ③ 채점

```bash
cd /data/workspace/yyj/data/ss_eval

python3 scripts/eval_kie.py --types receipt --pred-dir vlm_output/exp004_kie
```

결과는 `runs/<타임스탬프>_eval_kie.json` 에 문서별로 저장됩니다.

### ④ 비교표 (선택)

```bash
cd /data/workspace/yyj/data/ss_eval
python3 scripts/report_receipt_table.py receipt
```

DocStudio base / high / exp_004 / exp_009 를 한 표로 출력합니다.

## 5. DocStudio 와 다른 점

| 항목 | DocStudio high | 저희 |
|---|---|---|
| **전처리(레이아웃 검출)** | **있음** | **없음** |
| 가중치 | 병합 후 bf16 저장 | 베이스 + 어댑터 분리 로드 |
| 서빙 엔진 | vLLM 3.1.7 | transformers `generate` |
| 디코딩 설정 | 엔진 기본값 | greedy / max_new 3,072 |

**receipt 결과의 0.9032 vs 0.8956 차이는 이 조건 차이를 포함한 값**입니다.
동일 조건으로 보려면 GPU 7번 엔진에 exp_009 를 병합해 같은 API로 재측정하는 방법이 있습니다.
