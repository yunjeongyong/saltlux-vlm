## 개요

exp_012 학습셋 **47,686행**에 쓰인 프롬프트를 전수 집계했다.
고유 지시문은 **38종**이며, 태스크(문서 유형)는 **21종**이다.

학습 시 `train_vlm.py` 는 그 값을 챗 템플릿에 끼울 뿐이다.

```python
# scripts/train_vlm.py 113~133행
user, asst = r["messages"][0], r["messages"][1]
msgs = [{"role": "user", "content": [
    {"type": "image"},
    {"type": "text", "text": user["content"].replace("<image>", "")}]}]
prompt = self.proc.apply_chat_template(
    msgs, add_generation_prompt=True, tokenize=False,
    enable_thinking=False)          # 사고 모드 끔
```

### 5. 실패 억제 지시문 — 1,900행 (3.98%)

**■ 지시문** (59줄 · 2,089자)

```
출력은 오직 하나의 HTML <table>이어야 한다. 사용할 수 있는 태그는 table, thead, tbody, tr, th, td, br이며, 사용할 수 있는 속성은 rowspan과 colspan뿐이다.

입력 이미지의 첫 번째 주요 표 영역을 원본 구조에 충실하게 복원한다. 규칙은 아래 우선순위로 적용한다.

1. 표 구조
- 원본의 행, 열, 셀 위치, 빈 셀 및 병합 구조를 보존한다.
- HTML 생성 전에 전체 표의 최하위 열 개수를 결정한다.
- 모든 행은 rowspan과 colspan을 적용한 후 동일한 최하위 열 구조에 맞아야 한다.
- 실제로 여러 행이나 열에 걸친 셀에만 rowspan 또는 colspan을 사용한다.
- 하나의 시각적 행을 여러 행으로 나누거나 여러 시각적 행을 하나로 합치지 않는다.

2. 셀 경계
- 셀은 테두리선뿐 아니라 정렬, 여백, 배경 영역, 텍스트 위치 및 인접 행의 반복되는 열 구조를 종합하여 판단한다.
- 경계선이 흐리거나 끊겨 있어도 같은 위치에 열이 반복되면 별도 셀로 유지한다.
- 같은 행 안에 세로 경계가 있으면 내용이 짧더라도 각각 별도 셀로 유지한다.
- 날짜의 연도, 월, 일이 각각 경계로 나뉘어 있으면 별도 셀로 출력한다.
- 라벨과 값 사이에 경계가 있으면 별도 셀로 출력한다.
- 전화번호, 날짜, 코드 또는 금액을 인접한 라벨 셀에 합치지 않는다.
- 동의/동의하지 않음, 예/아니오, 라벨/입력란, 항목/체크 칸처럼 위치가 구분된 영역은 각각 별도 셀로 유지한다.
- 서로 다른 셀의 내용을 |, /, 공백 또는 <br>로 연결해 하나의 셀로 합치지 않는다.
- <br>은 동일한 셀 내부의 실제 줄바꿈에만 사용한다.

3. 빈 셀과 체크박스
- 경계가 있는 빈 셀과 빈 입력란을 삭제하거나 주변 셀과 합치지 않는다.
- 빈 셀은 <td></td>로 출력한다.
- 넓게 병합된 하나의 빈 입력 영역을 여러 가상 셀로 나누지 않는다.
- 체크되지 않은 체크박스는 □, 체크된 체크박스는 ☑로 출력한다.
- 체크박스가 독립된 셀에 있으면 별도 셀로 유지한다.
- HTML 폼 요소는 생성하지 않는다.

4. 헤더와 텍스트
- <th>는 실제 데이터 열 또는 행을 구조화하는 헤더에만 사용한다.
- 성명, 주소, 연락처, 계좌번호, 서명 같은 입력 양식 라벨은 <td>로 출력한다.
- 확실하지 않으면 <td>를 사용한다.
- 각 셀의 텍스트, 숫자, 날짜, 기호 및 문장부호를 보이는 그대로 옮긴다.
- 텍스트를 수정, 번역, 요약, 정규화하거나 주변 문맥으로 추론하지 않는다.
- 한글, 영문, 숫자, 괄호 및 문장부호의 문자 체계를 변경하지 않는다.
- ':'를 '：'로, '.'를 '。'로, '('를 '（'로 변환하지 않는다.
- 읽을 수 없는 글자를 문맥상 자연스러운 다른 단어로 수정하지 않는다.
- 보이지 않는 반복 값을 임의로 채우지 않는다.

5. 표 영역과 종료 지점
- 하나의 연속된 표 격자만 출력한다.
- 행·열 경계가 연결되거나 같은 열 정렬이 반복되는 동안만 동일한 표로 판단한다.
- 넓은 여백, 일반 문단, 서명 영역 또는 격자가 없는 설명문이 나오면 해당 지점에서 표가 끝난 것으로 판단한다.
- 일반 문단이나 서명 영역을 colspan 셀로 만들어 표에 포함하지 않는다.
- 표 아래에 다른 독립된 표가 있어도 첫 번째 주요 표가 끝나면 생성을 종료한다.
- 페이지 번호, 푸터, 용지 규격, 캡션 및 워터마크는 제외한다.

6. HTML 형식과 종료
- class, style, border 및 기타 속성을 사용하지 않는다.
- input, div, span, b 및 기타 허용되지 않은 태그를 사용하지 않는다.
- 마크다운 코드 블록을 사용하지 않는다.
- 행, 셀, 텍스트 또는 HTML 조각을 반복 생성하지 않는다.
- 마지막 표 행을 출력한 즉시 </table>로 닫는다.

출력 전에 모든 태그가 닫혔는지, 모든 행의 최하위 열 개수가 일치하는지, 분리된 셀이나 빈 셀을 누락하지 않았는지, 표 외부 텍스트가 포함되지 않았는지 확인한다.

최종 출력에서 input, style, class, border, span, div, b 및 마크다운을 제거한다. <table>부터 </table>까지만 출력한다.
```

**■ 사용 문서 유형** — `receipt_crop_table` 1,900행

## 6. 주요 지시문에 담긴 의도

**■ OCR 지시문 (20줄) — 반복 폭주 억제**

```
각각의 보이는 줄은 최대 한 번만 출력한다.
이미지에 실제로 반복되지 않은 문자, 단어, 기호 또는 수식 조각을 반복하지 않는다.
마지막으로 보이는 내용을 전사한 즉시 출력을 종료한다.
```

- exp_004 는 반복 폭주 7건이었으나 exp_009 이후 0건이다

**■ 표 지시문 (59줄) — 셀 경계 붕괴 억제**

```
경계선이 흐리거나 끊겨 있어도 같은 위치에 열이 반복되면 별도 셀로 유지한다.
날짜의 연도, 월, 일이 각각 경계로 나뉘어 있으면 별도 셀로 출력한다.
전화번호, 날짜, 코드 또는 금액을 인접한 라벨 셀에 합치지 않는다.
경계가 있는 빈 셀과 빈 입력란을 삭제하거나 주변 셀과 합치지 않는다.
```

- 표 행 붕괴가 최대 실패 유형이라 프롬프트로 눌렀다
