# saltlux-vlm

LUXIA VLM(영수증·문서 이해) 데이터셋 구축 및 학습·평가 파이프라인 스크립트.

## 구성

- `scripts/` — 데이터 구축, 학습셋 생성, 추론, 평가, 시각화 스크립트 (Python 122개 / Shell 5개)
- `LUXIA_VLM_학습현황_3.xlsx` — 실험별 학습·평가 현황 기록

## 스크립트 분류

| 접두사 | 용도 |
|---|---|
| `build_*` | 학습셋·평가셋·패널 구축 |
| `viz_*` | 데이터셋/GT/리포트 시각화 (HTML·PNG) |
| `infer_*`, `eval_*`, `score_*` | 추론 실행 및 성능 평가 |
| `make_*`, `update_*` | 라벨링 워크시트·실험 로그 생성 및 갱신 |
| `sync/` | 데이터 패키지 동기화 |

## 데이터

원본 이미지·JSON 데이터셋(`receipt_data/`, `vlm_dataset_upload/`, 약 16GB)은 용량 문제로
저장소에 포함하지 않으며 별도 스토리지에서 관리합니다.

## 자격증명

API 키는 코드에 포함하지 않고 `--api-key-file` 인자로 외부 파일 경로를 전달합니다.
